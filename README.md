# Robot Demo

Proyecto listo para GitHub Pages.

1. Crea un repositorio público en GitHub.
2. Descomprime el ZIP.
3. Sube el contenido de la carpeta `robot-demo` al repositorio.
4. Ve a **Settings > Pages**.
5. Selecciona **Deploy from a branch**, rama **main**, carpeta **/(root)**.
6. Guarda y espera la URL pública.

La página inicial es `index.html`.
